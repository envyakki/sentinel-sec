# Security Policy & Vulnerability Disclosure

## Supported Versions
SentinelSec actively maintains the following release versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We take the security of SentinelSec and the codebases it audits seriously.
If you discover a security flaw or bypass in the AST scanner or regex engine:

1. **Do not create a public issue.**
2. Send report details to **`akshchik12@gmail.com`**.
3. Include the vulnerable pattern, reproduction script, and AST node details.
4. We acknowledge receipt within 24 hours and publish patches promptly.
